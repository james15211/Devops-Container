One network, three services

Endpoints

The backend container exposes a small JSON API you can call from anywhere.

GET/itemsList all items
GET/items/:idGet a single item
POST/itemsCreate an item
PUT/items/:idUpdate an item
DELETE/items/:idDelete an item
GET/healthContainer & database status
